# Iron Covenant concept crops

Cut from `assets/art/iron-covenant-board.png` (1312x1199) by `make_crops.py`.

`variant-b-artillery/` holds Variant B (artillery platform) and six component close-ups.
Each has a `native/` file (exact board pixels) and a `-4x.png` file (Lanczos upscale plus
a light unsharp mask). **The upscales add no detail.** The source panel is only 324x336 px,
so the close-ups hold 80-185 px of real detail. For 3D build reference, regenerate at higher
resolution with an image tool if finer detail is needed.
