# Sentinel concept art (pilot walker, 2026-11-04)

Made with Meshy image-to-image (nano-banana, 3 credits each, 18 credits in all) from `docs/style-bible/covenant.md`
through `tools/meshy/prompts.py`. References: the Sentinel crop and Covenant hero from the three-faction board, the
approved Paladin front view, and the Covenant variant B artillery platform. Originals and `source.json` per task are in
the project folder `meshy-sources/sentinel/`; the ledger is `meshy-sources/ledger.json`.

| File | What |
| --- | --- |
| `concept-sheet.jpg` | everything on one page |
| `hero-roll1.jpg` | proposed north star: clean three-quarter view on grey, no cloak, easiest to model |
| `hero-roll2.jpg`, `hero-roll3.jpg` | alternates with cloaks and scenery (better as card painting, harder to cut into parts) |
| `turnaround-front/side/back.png` | front, side and back views of roll 1 (one multi-view task) |
| `partsheet.png` | the walker taken apart (card art source) |

Known gaps: the back view's legs are drawn with exposed brass pistons where the front has plate; the side view is
narrow and soft; the part sheet has no left arm and shows the legs twice (a re-roll with a stricter prompt was worse).
Not spent yet: any 3D credits. Balance 178.
