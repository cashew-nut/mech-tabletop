# Concept art

Reference boards Luke generated for the look of the war-walkers. The 3D models
and the faction rules are aiming at these, so check new work against them.

| File | What it shows |
| --- | --- |
| [iron-covenant-board.png](iron-covenant-board.png) | The first board, for the Iron Covenant: gothic cathedral knights in black, gold and crimson. It has a hero shot, close-ups of the helm, hand, glowing furnace chest and sunburst pauldron, three variants (A heavy assault walker, B artillery platform, C light recon), a turnaround of the primary mech, a 12-15m scale comparison, environment mood and the colour palette. |
| [three-factions-board.png](three-factions-board.png) | The three-faction board, with one column each for the Iron Covenant (Paladin, Sentinel, Lancer), the Ashen Foundries (Brute, Artillery, Scavenger) and the Reliquary (Seer, Wraith, Goliath). Each column has the faction blurb, the three classes, detail close-ups, signature weapons and systems, colours and materials, orthographic views, scale and environment mood. |

The plan for rebuilding the models against these boards is in the project's
model rebuild plan, and the faction data lives under `data/`.
